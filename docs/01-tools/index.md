# Tools

Before you can learn machine learning, you need a place to write code, a way to
run it, and a way to save it. That is what this module sets up. Five tutorials,
about two and a half hours in total.

Do them in order. Each one assumes the one before it is done.

    ---

    Get your accounts working: the intranet, Slack, GitHub, and the cloud

-   :material-source-branch: **Git and GitHub**

    ---

    Save snapshots of your work, put them online, and get your first project

    [Start](git-and-github.md)

-   :material-notebook-outline: **Jupyter notebooks**

    ---

    Run code one piece at a time and see the result immediately. This is where
    most of your experiments will happen.

    [Start](notebook-setup.md)

-   :material-microsoft-visual-studio-code: **VS Code**

    ---

    The editor you will build real applications in, with Linux running
    underneath it.

    [Start](vscode-setup.md)

-   :material-language-python: **Python warm up**

    ---

    Loops, functions, lists, and dictionaries on realistic nested data. The

    [Start](python-warm-up.md)

!!! tip "Finish one before starting the next"

    It is tempting to skim all five and set things up later. Do not. Every
    tutorial after this module assumes your environment already works, and
    fixing it in week four costs far more than fixing it now.

## What you will have at the end

A working Linux environment, code running in two places (notebooks for
experiments, VS Code for real programs), and a GitHub repository with your
first commits in it.
